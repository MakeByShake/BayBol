# BayBol Visa — сайт «Грин-карта DV-2027»

Одностраничный сайт для подачи заявок на грин-карту. Все заявки уходят в WhatsApp,
базы данных и личного кабинета нет. Сайт работает на русском и казахском.

Почти всё, что может понадобиться поменять, лежит в **двух файлах**:

| Что меняем | Файл |
|---|---|
| Цены, телефоны, адрес, Instagram, режим работы, фото | `src/config/site.ts` |
| Даты лотереи (открытие, закрытие, результаты) | `src/config/dv.ts` |
| Тексты на русском | `src/i18n/ru.ts` |
| Тексты на казахском | `src/i18n/kz.ts` |

Номера строк ниже указаны на момент сдачи сайта. Если файл уже правили, ищите строку по тексту.

> Как править файл прямо на GitHub: откройте файл → значок карандаша ✏️ справа вверху →
> поменяйте значение → внизу зелёная кнопка **Commit changes**. Vercel сам пересоберёт
> сайт за 1–2 минуты.
>
> Меняйте только то, что **внутри кавычек** `'...'` или цифры. Запятые и скобки не трогайте.

## 💰 Как поменять цену

Файл `src/config/site.ts`, строки **44–46**:

```ts
single: 8000,  // один заявитель
couple: 15000, // супруги вместе — за двоих
child: 2000,   // каждый ребёнок до 21 года
```

Пишите цифры **без пробелов** (`10000`, а не `10 000`). Цена сама обновится везде: на
первом экране, в карточках тарифов, в калькуляторе, на нижней кнопке и в тексте сообщения
WhatsApp.

> Картинка для соцсетей (`public/og-image.png`) — это готовый рисунок, на нём цена тоже
> написана. После смены цены попросите программиста выполнить команду `npm run brand`,
> и картинка перерисуется.

## 📞 Как поменять телефон WhatsApp

Файл `src/config/site.ts`, строки **24–25**:

```ts
{ number: '77066419060', display: '+7 706 641 90 60' }, // Менеджер 1 (основной)
{ number: '77779311019', display: '+7 777 931 10 19' }, // Менеджер 2
```

- `number` — только цифры, начиная с `77...`, без `+` и пробелов. На этот номер ведут ссылки.
- `display` — как номер показывается на сайте.

**Распределение клиентов между менеджерами** — строка **29**:

- `whatsappMode: 'first'` — все главные кнопки ведут к Менеджеру 1 (так сейчас);
- `whatsappMode: 'random'` — каждый посетитель случайно попадает к одному из двух менеджеров.

Instagram — строка **32**, режим работы — строки **37–40**, адрес — строки **13–16**,
способы оплаты — строки **51–54**.

## 📅 Как поменять дату открытия приёма

Файл `src/config/dv.ts`, строка **8**:

```ts
registrationOpensAt: '2026-11-01T00:00:00-05:00',
```

Это **1 ноября 2026, 00:00 по Вашингтону** (= 10:00 по Алматы). Когда Госдеп объявит точное
время, поменяйте дату и время, а `-05:00` оставьте как есть.

Таймер на сайте пересчитается сам: «до открытия» → «идёт приём» → «приём завершён».

Другие даты в том же файле:

| Строка | Что это |
|---|---|
| 9 | `registrationDays: 30` — сколько дней длится приём |
| 10 | `registrationClosesAt: null` — точная дата закрытия. Если Госдеп её назовёт, впишите в кавычках, например `'2026-12-01T12:00:00-05:00'`. Пока `null` — сайт считает «открытие + 30 дней» |
| 11 | `resultsBy` — до какого дня объявят результаты |
| 12 | `visasUntil` — до какого дня выдают визы |
| 18 | `factsCheckedAt` — дата «информация актуальна на…» в подвале. Обновляйте, когда сверяете факты |

Формат дат: `'ГГГГ-ММ-ДД'`, например `'2026-12-03'`.

## 🖼 Как заменить фото (офис, команда)

Пока фото нет, на их месте показываются аккуратные заглушки. Чтобы поставить настоящие:

1. Подготовьте фото в формате **WebP** (любой онлайн-конвертер «JPG to WebP»), шириной
   около 1200 px.
2. Назовите файлы **точно так**:
   - `office.webp` — фото офиса (широкое);
   - `team-1.webp`, `team-2.webp` — фото команды (квадратные).
3. Положите их в папку **`public/`** (на GitHub: зайти в папку `public` → **Add file** →
   **Upload files**).

Фото появятся на сайте сами. Чтобы назвать файлы иначе или добавить ещё фото команды,
поменяйте список в `src/config/site.ts`, строки **59–62**.

## ✏️ Как поменять тексты

Все тексты лежат в `src/i18n/ru.ts` (русский) и `src/i18n/kz.ts` (казахский). Найдите
нужную фразу через поиск (Ctrl+F) и поменяйте текст в кавычках. **В обоих файлах**, чтобы
языки не разошлись.

Слова в фигурных скобках, например `{price}` или `{program}`, не трогайте: сайт сам
подставит на их место цену, дату и так далее.

## ⚠️ Проверить перед запуском

1. **Риски для граждан Казахстана** — ответ в FAQ (`ru.ts`, строка **350**; `kz.ts`, строка
   **353**, помечено `// ПРОВЕРИТЬ ПЕРЕД ЗАПУСКОМ`). Сверьте, актуальна ли информация о
   приостановке иммиграционных виз.
2. **Казахский текст** переведён вручную, но его стоит вычитать носителю языка
   (в начале `kz.ts` есть пометка).
3. **Способы оплаты** в FAQ — пока общая формулировка (`site.ts`, строки **51–54**).
4. **Адрес сайта** — `src/config/site.ts`, строка **7**. Если на Vercel будет другой адрес
   или свой домен, впишите его сюда: от него зависят ссылки в соцсетях и `sitemap.xml`.

## 🚀 Публикация на Vercel (один раз)

1. Зайдите на **vercel.com** и войдите через GitHub.
2. **Add New → Project** → выберите репозиторий **BayBol** → **Import**.
3. Ничего не меняйте (Vercel сам поймёт, что это Vite) → **Deploy**.
4. Через 1–2 минуты получите ссылку вида `baybol.vercel.app`. Если адрес другой — впишите
   его в `src/config/site.ts`, строка 7.
5. Свой домен (например `baybol.kz`): в проекте на Vercel → **Settings → Domains**.

Дальше любое изменение на GitHub автоматически публикуется на сайте.

## Полезное

- **Варианты логотипа**: страница `/logo-preview` (скрыта от поисковиков). Выбран вариант
  «Золотая монета + траектория». Файлы: `public/logo-full.svg`, `public/logo-mark.svg`,
  `public/favicon.svg`; копии — в `src/assets/logo/`.
- **Шрифты**: заголовки — Geologica, текст — Onest. Оба полностью поддерживают казахские
  буквы (Ә Ғ Қ Ң Ө Ұ Ү Һ І). Unbounded, указанный в задании, их не поддерживает, поэтому
  заменён.

### Для программиста

```bash
npm install
npm run dev      # локальный просмотр: http://localhost:5173
npm run build    # сборка в dist/
npm run brand    # перегенерировать логотипы, favicon, og-image (нужен Python 3 + fonttools)
```

React 19 + Vite + TypeScript, Tailwind CSS 3, Framer Motion, lucide-react. Без бэкенда.
SEO-теги, schema.org (LocalBusiness + FAQPage), `robots.txt` и `sitemap.xml` собираются
при сборке из `config` (плагин в `vite.config.ts`).
